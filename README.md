# Arfan Ali — Portfolio Website

A personal portfolio website for Arfan Ali, an aspiring designer, showcasing skills, interests, and design journey.

🔗 **Live site:** https://arfan199076-commits.github.io/arfanali.github.io/

## About

This site is a single-page, responsive portfolio built with plain HTML, CSS, and vanilla JavaScript — no build step or framework required.

## Sections

- **Home** — Introduction and call to action
- **About** — Background and design journey
- **Skills** — Visual Design, UI/UX, Graphic Design, Web Design
- **Portfolio** — Practice projects and learning experiments
- **Contact** — Email, LinkedIn, GitHub

## Tech Stack

- HTML5
- CSS3 (custom properties, grid, flexbox, animations)
- Vanilla JavaScript (smooth scroll, scroll-triggered fade-ins, mobile menu toggle)

## Local Development

No build tools needed — just open `index.html` in a browser, or serve it locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deployment

Hosted via **GitHub Pages**, served from the `main` branch, root (`/`) directory.
